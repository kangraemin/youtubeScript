# 모바일 경제 요약 웹 전체 개편

사용자 지시: 모바일에서 주로 이용하며, 기존 용어·챕터를 포함한 전체 디자인에서 무엇을 읽어야 할지 알 수 없다. 홈·채널·상세·검색·로딩 화면을 한 체계로 개편한다.

- 시각: 따뜻한 밝은 바탕, 짙은 잉크색 제목, 녹색을 주요 탐색에 사용. 매수/매도는 텍스트와 색을 함께 표시. 정보의 위계를 글자 크기·간격·카드 종류로 구분.
- 홈: 최신 요약으로 바로 진입. 채널 선택과 검색을 간결하게 제공. 영상 제목·읽을 내용·발언 종류·채널/날짜를 분리.
- 상세: 한눈에 보기 → 출연자 매수/매도 발언 → 시장의 조건과 경제 개념 → 시간별 목차. 용어는 이름과 풀이를 바로 보이고, 챕터는 시간선으로 표시. 숨겨진 본문은 펼쳐 읽을 수 있게 보존.
- 데이터: 기존 v2/v3 및 경량 피드 RPC 지원, 데이터베이스 스키마나 원문 수정 없음. 의견을 서비스의 투자 권유로 재표현하지 않음.
- 확인: 기존 reader 보존 테스트, 타입/프로덕션 빌드, 실제 데이터로 모바일 390px·좁은 360px·데스크톱 화면. 검색·필터·상세·목차·근거 펼치기·뒤로가기 확인.
- 게시: 로컬 검증을 완료한 결과를 리뷰 가능하게 준비한 뒤 배포를 처리한다.
