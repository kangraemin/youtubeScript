# 모바일 중심 전체 디자인 검증

Preview: https://web-dd1jf0fsm-remin1994-3460s-projects.vercel.app
Production은 변경하지 않음. feature/mobile-reader-redesign 브랜치에서 검토 후 반영.

## 구현
- 홈·채널·전체 목록·검색·상세·로딩에 밝은 종이색/녹색 타이포그래피 적용.
- 영상 카드는 출처/제목/핵심/내용 태그/읽기 순서. 모바일 한 열, 데스크톱 두 열.
- 매매 발언: 행동·조건·종목·화자·근거. 경제 용어: 뜻과 맥락. 챕터: 시간/주제/원본 링크.
- 짧은 설명은 처음부터 노출. 긴 내용과 인용은 펼치되 전체 텍스트 HTML 보존.
- 기존 v2와 v3, 경량 feed RPC, 검색/쇼츠 필터/무한스크롤 로직 유지.
- 목차 이동 시 HTML scroll-padding과 section scroll-margin이 중복되어 선택 상태가 이전 섹션에 남는 문제 수정. 실제 배포본에서 대상 top=86px·aria-current 일치 확인.

## 검증
- `npm run build`: 로컬 및 Vercel preview 성공, 타입 검사 포함.
- `node --test tests/reader.test.cjs`: 9/9 성공. v2 전체 본문 보존·v3 조건/맥락/인용/6번째 이후 항목·URL 검증.
- 실제 브라우저 390×844 홈/상세/검색, 360×800 채널: 가로 넘침 없음.
- 삼성전자 검색: 19개 카드·25개 강조표시 확인.
- 챕터 11개 중 5개 기본 노출, 더보기 클릭 후 11개 표시 확인.
- 미리보기에서 경제 용어/영상 목차 클릭 후 현재 탭 선택 일치.
- 스크린샷은 이 폴더의 jpg. 실제 데이터 사용, 데모용 성과 수치 생성 없음.

## 데이터 별도 확인 필요
- `WtEo31SpSeI`: 요약에 1:21:18·1:29:36 링크가 있으나 YouTube 원본 UI에서는 총 1:16:38로 표시됨. DB duration은 약 94분. 원본 편집/인트로 제거 가능성이 있으나 원인 미확정. 디자인과 분리하여 Claude가 원본과 타임스탬프를 감사해야 함. 정확한 구간 이동의 성공 증거로 이 항목을 사용하지 않는다.
- Preview 환경의 Supabase 변수가 미등록되어 최초 빌드 실패. 기존 NEXT_PUBLIC 두 변수만 해당 deployment의 build/runtime에 주입하여 해결. 운영환경 설정 변경 없음.
